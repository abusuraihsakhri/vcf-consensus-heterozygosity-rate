Undefined ratios are shown as N/A, not zero. Het rate = heterozygous / fully called diploid genotypes. Missing rate = missing or partially missing GT calls / retained genotype records.

Counting rules: Ti/Tv uses each eligible A/C/G/T REF→ALT SNP allele once per site, including multiallelic sites; genotype counts include SNVs and non-SNV records. Haploid and polyploid called genotypes are reported separately. No frequency, clinical-risk, or diagnostic classification is inferred.

Source and CLI: GitHub repository. No browser storage or external analytics.
